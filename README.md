## Proyectos

### 1. Buscador de exoplanetas — código abierto

Busca planetas fuera del Sistema Solar en datos reales del satélite TESS de la NASA, descarta falsos positivos con 14 pruebas físicas y ordena los candidatos con un modelo de machine learning.

- 0 falsas alarmas en 120 estrellas reales con la señal invertida.
- 94 % de planetas simulados recuperados.
- Clasificador con AUC 0,90, validado sin fuga de datos.

**Python · astropy · lightkurve · scikit-learn**
[Ver repositorio →](https://github.com/cutoxx/buscador-exoplanetas)

### 2. MiTribuna — producto propio, código privado

SaaS multi-tenant donde cada club deportivo tiene su propia página web con su identidad visual, más un panel para administrar socios, pagos, noticias y auspiciadores.

Lo que más me interesó resolver: que ningún club herede los colores de otro y que el texto siempre sea legible, con un test automático que lo verifica.

**Next.js 15 · TypeScript · Supabase · Tailwind · Playwright**
[Leer el caso de estudio →](https://github.com/cutoxx/mitribuna)

### 3. HydroStock — Proyecto de Título en equipo, código privado

Sistema de gestión para una pyme que vende e instala mangueras hidráulicas: inventario, ventas y bodega, con una capa de IA en desarrollo para identificar productos por foto o texto. Hoy esa pyme lo lleva todo en cuadernos y Excel.

**Django · DRF · Next.js · Supabase · Render · Vercel**
[Leer el caso de estudio →](https://github.com/cutoxx/hydrostock)
